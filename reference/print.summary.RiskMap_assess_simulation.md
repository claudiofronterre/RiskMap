# Print Simulation Results

Prints a concise summary of simulation results from a
`RiskMap_assess_simulation` object, including average metrics by
category and a summary of overall correct classification (CC).

## Usage

``` r
# S3 method for class 'summary.RiskMap_assess_simulation'
print(x, ...)
```

## Arguments

- x:

  An object of class `summary.RiskMap_assess_simulation`, as returned by
  `summary.RiskMap_assess_simulation`.

- ...:

  Additional arguments (not used).

## Value

Invisibly returns `x`.
