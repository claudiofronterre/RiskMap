# Extract fitted values from a RiskMap model

Extract fitted values from a RiskMap model

## Usage

``` r
# S3 method for class 'RiskMap'
fitted(object, type = c("response", "link"), ...)
```

## Arguments

- object:

  A fitted `RiskMap` object.

- type:

  Whether to return fitted values on the response or link scale.

- ...:

  Additional arguments, currently unused.

## Value

A numeric vector, or `NULL` when final conditional sampling was skipped
for a non-Gaussian model.

## Examples

``` r
data(italy_sim)

fit <- glgpm(
  formula = y ~ gp(),
  data = italy_sim[1:100,],
  family = "gaussian",
  return_samples = TRUE,
  messages = FALSE
)

fitted(fit)
```
