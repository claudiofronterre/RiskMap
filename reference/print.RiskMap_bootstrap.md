# Print a parametric bootstrap

Prints the summary of a parametric bootstrap from
[`parametric_bootstrap()`](https://claudiofronterre.github.io/RiskMap/reference/parametric_bootstrap.md).

## Usage

``` r
# S3 method for class 'RiskMap_bootstrap'
print(x, ...)

# S3 method for class 'summary.RiskMap_bootstrap'
print(x, ...)
```

## Arguments

- x:

  A `RiskMap_bootstrap` or `summary.RiskMap_bootstrap` object.

- ...:

  Not used.

## Value

`x`, invisibly.
