# Plot Method for RiskMap_variogram Objects

Plots the empirical variogram generated by
[`variogram`](https://claudiofronterre.github.io/RiskMap/reference/variogram.md)

## Usage

``` r
# S3 method for class 'RiskMap_variogram'
plot(x, plot_envelope = TRUE, color = "royalblue1", show_pairs = FALSE, ...)
```

## Arguments

- x:

  The output generated by the function
  [`variogram`](https://claudiofronterre.github.io/RiskMap/reference/variogram.md).

- plot_envelope:

  A logical value indicating if the global envelope of spatial
  independence generated using the permutation test must be displayed
  (`plot_envelope = TRUE`) or not (`plot_envelope = FALSE`). By default
  `plot_envelope = TRUE`. Note: if `n_permutations` was 0 when running
  [`variogram`](https://claudiofronterre.github.io/RiskMap/reference/variogram.md),
  no envelope can be generated; a warning is raised and the envelope is
  skipped.

- color:

  If `plot_envelope = TRUE`, it sets the fill colour of the envelope;
  run `vignette("ggplot2-specs")` for more details on this argument.

- show_pairs:

  A logical value indicating if each point should be labelled with the
  number of pairs of locations in its distance class. A semivariance
  estimated from few pairs is unstable, so the labels help to judge how
  much each point can be trusted, and to choose the distance classes in
  [`variogram`](https://claudiofronterre.github.io/RiskMap/reference/variogram.md).
  By default `show_pairs = FALSE`.

- ...:

  Currently unused.

## Value

A `ggplot` object representing the empirical variogram plot, optionally
including the envelope of spatial independence.

## Details

This function plots the empirical variogram, which shows the spatial
dependence structure of the data. Each point is the semivariance of one
distance class, and classes without pairs are omitted. Points are not
joined by lines, because the empirical variogram is only defined for the
distance classes. Both axes start at zero. If `plot_envelope` is set to
`TRUE`, the plot also includes a simultaneous extreme-rank-length
envelope for spatial independence, and points that fall outside it are
drawn in red.

## See also

[`variogram`](https://claudiofronterre.github.io/RiskMap/reference/variogram.md)

## Examples

``` r
data(galicia)
galicia_variogram <- variogram(galicia, variable = "lead",
                               distance_units = "km", seed = 1)
plot(galicia_variogram, show_pairs = TRUE)
```
