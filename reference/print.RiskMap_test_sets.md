# Print test sets

Gives the number and the sizes of the test sets and how far the test
locations are from their training data.

## Usage

``` r
# S3 method for class 'RiskMap_test_sets'
print(x, ...)
```

## Arguments

- x:

  Test sets from
  [`create_test_sets()`](https://claudiofronterre.github.io/RiskMap/reference/create_test_sets.md).

- ...:

  Not used, and an error if given, so that a misspelt argument is not
  ignored.

## Value

Invisibly returns `x`.
